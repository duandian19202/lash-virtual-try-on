# TEST-C-1013-010-DBK 3D Notes

## Intent

Test SKU for a realistic calibrated cat-eye lash asset.

Target look:

- outer-longer cat-eye mapping
- satin deep black PBT fiber
- soft black root band
- daily-to-defined density
- realistic fiber depth, taper, and light response

## Mapping

```text
inner      8mm   density 0.68
mid-inner  9mm   density 0.86
center     10mm  density 0.98
mid-outer  12mm  density 1.08
outer      13mm  density 1.12
```

## Review Checklist

- Root line is aligned near the bottom edge.
- Inner corner is short and light.
- Outer corner is longer but does not droop.
- Fibers have visible taper and varied depth.
- Highlights are subtle, not plastic.
- Transparent PNG has no white/gray background.
- Output can be used directly by the website as `assets/TEST-C-1013-010-DBK/main.png`.
